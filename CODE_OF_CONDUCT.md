# Code de conduite

## Notre engagement

Nous nous engageons a faire de la participation a ce projet une experience accueillante, sans harcelement, pour tous.

## Comportements attendus

- Respect et langage professionnel
- Critiques constructives sur le code, pas sur les personnes
- Acceptation des retours bienveillants

## Comportements inacceptables

- Harcelement, insultes, discrimination
- Publication de donnees privees sans consentement
- Toute conduite inappropriee dans un contexte professionnel

## Application

Les maintainers peuvent supprimer contributions ou issues ne respectant pas ce code.

Signalements : via GitHub Issues en mentionnant « code de conduite » ou contact prive du mainteneur.

Adaptation du [Contributor Covenant](https://www.contributor-covenant.org/) v2.1.
